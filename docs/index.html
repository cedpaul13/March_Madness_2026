02 / Method02 / Méthode

How the model worksComment fonctionne le modèle

XGBoost adjusts points per possession for opponent strength. The other two signals account for travel distance, recent results and rest.

XGBoost ajuste les points par possession selon le niveau des adversaires. Les deux autres signaux tiennent compte des déplacements, des résultats récents et du repos.

My only manual adjustments were for injuries: Duke −6.5%, North Carolina −11%, Michigan −3%, all set before tip-off. Monte Carlo simulations then estimated each team’s chances through the bracket.

Mes seuls ajustements manuels concernaient les blessures : Duke −6,5 %, North Carolina −11 %, Michigan −3 %, avant le tournoi. Les simulations Monte Carlo ont ensuite estimé les chances de chaque équipe sur son parcours.
